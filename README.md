# 穿搭工作台 (Outfit Studio)

浅色简约风的穿搭管理静态网站。无需后端，纯 HTML + CSS + 原生 JS，可直接部署到 Netlify。

## 功能
- **底部 2 个导航图标**：穿搭方案、个人主页。
- **穿搭方案页**
  - 顶部长方形方格：展示「最常穿的穿搭」（每周更新，依据衣物库自动刷新）。
  - 下方 4 个正方形方格：春 / 夏 / 秋 / 冬 四季穿搭，点击查看。
- **个人主页**
  - 上传衣物：从相册选图 → 前端近似抠图换白底 → 归入 11 个服饰分类之一。
  - 搭配衣物：左上角小圆打开服饰分类侧栏（不盖满全屏）→ 下方显示分类衣物 →
    双击衣物弹出删除键 → 上方白底画布拖拽组合 → 添加键选季节保存 → 右下角完成键退出。

## 本地预览
```bash
cd /workspace
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署到 Netlify
1. 把本目录推到你的 Git 仓库（仓库地址请发我，我来关联）。
2. 在 Netlify 新建 site，关联该仓库，构建命令留空，发布目录为 `/`（根目录）。
3. 或直接使用仓库内 `netlify.toml`，拖拽部署即可。

## 说明
- 数据保存在浏览器 `localStorage`，换设备/清缓存会丢失，后续可接后端持久化。
- 「每周更新 / 最常穿」基于本地衣物库计算，纯前端定时刷新，无需服务器。
- 抖音/小红书爬取不在本版需求内（本版需求已无首页爆款流）。
